# Дообучение детектора

Всё выполняется локально. Кадры, разметка и веса лежат в `data/` и `models/` и не коммитятся. Облачные сервисы разметки (Roboflow и т. п.) использовать нельзя.

Классы и их порядок задаёт `config/training_classes.json`: `person, cash, id_card, cash_bag, counter, stamp, folder, safe_key, personal_item, door, safe, laptop, currency_detector`. Порядок нельзя менять после начала разметки, новые классы только дописываются в конец. Дверь, сейф и ноутбук детектор находит без состояния, чтобы работать при любом ракурсе; открыт/закрыт и включён/выключен определяются отдельно по найденной рамке.

## 1. Кадры

```bash
.venv/bin/python scripts/prepare_dataset.py /путь/к/видео --moments moments.csv
```

- Видео делятся на обучение и проверку **по роликам** (по умолчанию 8 случайных в проверку, свои — через `--val имя1 имя2`). Деление сохраняется в `data/training/split.json` и при повторном запуске не меняется; новые ролики (свои съёмки) уходят в обучение.
- Берётся 1 кадр/с в полном разрешении, почти одинаковые кадры пропускаются.
- `moments.csv` (`video,timecode_sec`) — моменты нарушений и появления редких объектов (сумка, ключ, печать). Вокруг них ±3 с берётся 5 кадров/с.

## 2. Черновая разметка

```bash
.venv/bin/python scripts/prelabel.py
```

YOLOE-26 размечает кадры по текстовым подсказкам. Это только черновик: на наших видео он находит людей, но почти не находит деньги, удостоверения и мелкие предметы.

## 3. Ручное исправление (несколько человек, каждый на своём ноутбуке)

```bash
.venv/bin/python scripts/labeling_packages.py diyar aru temir dana
```

Каждый получает `data/labeling/<имя>.zip`: свои ролики целиком (обучающие и проверочные), черновики в формате X-AnyLabeling и `START.txt` с инструкцией. Пакеты передаются только напрямую: Tailscale, AirDrop, флешка — не через облака и мессенджеры.

Разметка в X-AnyLabeling с фиксированным списком классов: `xanylabeling --filename images --labels classes.txt --validatelabel exact --autosave --nodata`. Готовый кадр отмечается как проверенный: Cmd+Option+K (Ctrl+Alt+K) или Edit → Mark as Checked; в заголовке появится `[Checked]`. Галочки в списке файлов означают только наличие файла разметки. Кадры без отметки в обучение не попадают.

Неподвижные объекты (`door`, `safe`, `laptop`, `counter`) достаточно разметить на одном кадре ролика и отметить его проверенным. Затем закройте X-AnyLabeling и скопируйте рамки на остальные непроверенные кадры этого ролика:

```bash
.venv/bin/python scripts/propagate_static.py data/labeling/diyar/images
```

Копии помечены `copied`; при просмотре кадра их нужно только проверить.

Возвращённые JSON (архивы или папки) объединяются, можно по частям:

```bash
.venv/bin/python scripts/merge_labels.py returned/diyar.zip returned/aru.zip
```

Скрипт пишет YOLO-разметку, `train.txt`/`val.txt` только из проверенных кадров и `data.yaml`. Неизвестные классы и расхождения между людьми он выводит списком и пропускает.

Правила разметки:
- `cash` — одна рамка на пачку или веер купюр, лежащих вместе; отдельная купюра — отдельная рамка.
- `id_card` — только когда документ виден; в закрытой руке не размечать.
- `personal_item` — куртка, сумка, кружка или стакан на рабочем месте кассира.
- Объект, закрытый больше чем наполовину, не размечать.
- Удалять ложные рамки черновика, а не только добавлять пропущенные.

## 4. Обучение

```bash
.venv/bin/python scripts/train_detector.py            # YOLO26m, 1280, 150 эпох
.venv/bin/python scripts/train_detector.py --model yolo26s.pt --epochs 50   # быстрый прогон
```

На RTX 5090 нужен PyTorch под CUDA 12.8+ (cu128). Результат и метрики по классам — в `data/runs/cashdesk*/`.

## 5. Подключение и проверка

```
FORTE_DETECTOR=yolo
FORTE_MODEL_PATH=data/runs/cashdesk/weights/best.pt
```

Журнал пока использует имена `money` и `document`; соответствие `cash` и `id_card` им нужно добавить в `aliases` в `config/detector.json`. Метрики на проверочных роликах не доказывают устойчивость к другому ракурсу: проверьте на своих съёмках под другим углом.

## Отбор кадров и обучение на 5090

```bash
# все ролики при 5 кадрах/с, то же деление на обучение и проверку
cp data/training/split.json data/training/classes.txt data/training_5fps/
.venv/bin/python scripts/prepare_dataset.py videos --out data/training_5fps --fps 5 --min-change 0

# отбор N самых разных кадров (DINOv2 + косинус, локально); таблица покрытия помогает выбрать N
.venv/bin/python scripts/select_diverse.py --budget 3000
```

Обучение на 5090: окружение `~/forte-train/venv` (PyTorch cu128, ultralytics), набор копируется `rsync` в `~/forte-train/data/`, запуск `scripts/train_detector.py --device 0`. Метрики на кадрах с черновыми рамками показывают согласие с черновиком, а не точность: для честной оценки проверочные ролики размечают люди.
